## Instructions for Running Live Scripts

1. Open the live script in MATLAB Online by opening the links below.
2. "Save New Copy" of the repository when prompted in MATLAB Online. The repo will be saved in your MATLAB cloud storage (all UBC students will have their own cloud storage).
3. To run the live scripts:
(a) section by section, navigate to the **Editor** tab and click on **Run Section**
(b) in one go, navigate to the **Editor** tab and click on **Run**
